# ExamPulse

Personal exam-prep tracker for bank, regulator, tech, and PSU targets.

## Features

- All target exams from the OBC jobs canvas (dates, vacancies, pay, rounds, status)
- Detailed syllabus with coaching-aligned topics (EduTap, Oliveboard, Adda247, GATE Academy patterns)
- **Shared topic IDs** — tick Quant DI / ESI / GATE OS once; it syncs across every exam that shares that portion
- Subtopic checklists for fine-grained progress
- Progress saved in `localStorage`

## Run

```bash
cd exam-tracker
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
